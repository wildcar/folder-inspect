# folder-inspect

Utility for inspecting a folder tree on a local machine — project directories, git working
copies, document storages — and reporting what bloats it: very large files, archives, junk
(build output, caches, temp and OS files), and duplicate files. The goal is to clean
repositories and storages from files that should not be there.

Status: **discovery**. The stack, interface and exact scope are being chosen via
`docs/discovery-questionnaire.md`; no code yet.
